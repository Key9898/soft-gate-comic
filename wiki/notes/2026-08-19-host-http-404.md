# Impl 123 — Host HTTP 404 for unknown SPA paths

Unknown path shapes return HTTP 404 on Vercel. The HTML body is a post-build copy of `index.html` so the Impl 118/121 React recovery still paints. Known SPA routes rewrite to `index.html` (200). Catalog id misses stay 200.

## What shipped

- [`vercel.json`](../../vercel.json) explicit rewrites from `SPA_REWRITE_SOURCES`. No catch-all. No homepage redirect.
- Vite `closeBundle` copies `dist/index.html` → `dist/404.html`.
- `/webtoon/:id` and `/read/:webtoonId/:episodeNumber` stay 200 when the id/episode is missing (no catalog server).

## Verify

`npm run check`

After deploy: junk path `curl -sI` is 404; `/categories` is 200; `/webtoon/missing-id` and `/read/1/999` are 200.
