# i18n sweep (Impl 75)

Batch 6a of the six-batch audit overhaul: every remaining hardcoded user-facing English string in
the portal now goes through i18next (en + mm), and the Profile chart stops inventing data.

## What changed

- **HomePage release dates**: `Today/Yesterday/N days|months|years ago` literals →
  `libraryPage.today/yesterday/daysAgo` + new `monthsAgo`/`yearsAgo` keys.
- **WeeklyReadingChart honest + localized**: dropped the `episodeNumber × 5` fake-minutes math —
  bars now show real episodes read (`readEpisodeNumbers.length`) bucketed by last-read day; tooltip
  uses `profilePage.episodesUnit` plurals; day names via
  `Intl.DateTimeFormat(my-MM|en-US, { weekday: 'short' })` (fixed UTC Sunday anchor 2021-08-01);
  heading reuses existing `profilePage.weeklyActivity` key, value updated to
  "Weekly Reading Activity" / "အပတ်စဉ် စာဖတ်မှု" to match the episode-count truth.
- **AchievementsBadgeCenter**: 5 badge titles + descs → `profilePage.ach*` keys; heading reuses
  existing `profilePage.achievements`.
  - **Gotcha found**: `profilePage` already had unused `insights/weeklyActivity/genres/achievements`
    keys from an earlier design — adding a second `weeklyActivity` created a duplicate JSON key
    (last-one-wins) that silently shadowed the new value. Removed the duplicates and reused the
    legacy keys instead. Duplicate-key scan run on both locale files: clean.
- **LibraryPage**: Grid/List toggle labels (`gridView`/`listView`), `Ep. {n}/{total}` →
  `epOfTotal`, empty-state description + delete-dialog title inline `lang === 'mm'` ternaries →
  `emptyExplore`/`removeFromCollection` keys.
- **AuthLayout** tagline → `auth.tagline`; **Modal** close button title/aria → `common.close`;
  **BookCard**/**HeroBook3D** cover fallbacks → `common.cover`/`common.coverImage`.
- **Reader**: font-size buttons Small/Medium/Large → `legal.sizeSmall/Medium/Large` (Small
  previously mis-wired to `categories.all` — showed "All"); wallet unlock txn description →
  `readerPage.unlockTxnDesc` with `title[lang]` (was hardcoded English + `title.en`).
- **Notification seeds** (`src/lib/notifications/notifications.ts`): messages seeded via
  `i18n.t('notificationsPage.seedNewEpisode/seedSystem/seedPromo')` at creation time (frozen at
  seed language — stored per user once).
- **Locale-aware date fallbacks**: Comments + NotificationsPage bare `toLocaleDateString()` →
  `my-MM|en-US` with `{ month: 'short', day: 'numeric' }`; `formatters.formatDate` maps app lang
  `mm` → BCP 47 `my-MM`.
